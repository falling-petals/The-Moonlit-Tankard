# 月下酒馆 / 美术资产与视觉规范

## 方向

温暖的现代玻璃温室酒馆。白天为奶油白、浅木、鼠尾草绿和落日暖光；夜晚保持同一建筑与材质，以青蓝窗外雨景、珊瑚灯带与暖桌灯制造层次。避免传统中世纪石墙、火把和厚重仿古界面。

## 图集使用

原始PNG完整保留；manifest.json记录图集每格的原图坐标。运行时通过Canvas drawImage的源矩形读取，不修改原始图像。透明格的可见包围盒用于脚底锚点和角色统一高度，动画仍使用整格约定。

生成式图像的实际输出尺寸和像素簇可能不等于逻辑格，不能把整张概念图自动当成无缝Tilemap。地图交互坐标由游戏内容文件单独定义。

## 建议尺寸与排序

- 场景按统一3:2构图，Canvas逻辑坐标1536×1024；地图中的移动及交互以此坐标为准。
- 原始角色遵循32×48像素的块面语言；店长88、顾客86、AI员工77场景像素高。角色的透明可见包围盒对齐脚底。
- 家具脚底与人物脚底参与Y排序；桌面饮品和头顶提示位于角色层之上。
- 图层：日夜建筑底图 → 地面标记与地毯 → 家具/人物Y排序 → 桌面物品 → 天气与灯光 → 头顶提示 → 固定屏幕UI。
- Canvas关闭图像平滑；按设备DPR绘制。固定俯视角，使用覆盖视口的缩放并跟随店长，滚轮可放大到1.3倍；鼠标反变换到世界坐标后命中。
- 导航以16场景像素为搜索步长，人物留出14像素半径；可走地板区、桌椅和吧台碰撞在src/navigation.js中定义。寻路输出平滑航点，绘制与碰撞共用1536×1024世界坐标。

## 界面

场景铺满视口。角落使用奶油纸色和半透明墨绿HUD，底部保留简短店长状态及设施快捷键。走近员工时弹出底部奶油色小对话框；管理册在右侧浮动，不遮暗或模糊房间。设施与角色提示锚定世界坐标。可交互按钮有清楚的悬停、聚焦和禁用状态。

色板：背景#101C20；面板#17282B；文字#EFE5D0；次级文字#94A8A3；边框#41524A；金色#D9B878；鼠尾草#A8BE9C；珊瑚#D78673；夜光#6ECBD0。

完整生成提示词见 art-prototype/final/generation-prompts.json。使用内置image_gen生成，无额外图像API费用配置。

人类店长的独立生成提示词见 art-prototype/final/owner-generation-prompt.json；客串和活动图集的完整提示词见 art-prototype/final/party-generation-prompt.json。均使用内置image_gen并保留原图；图集共6张、96个透明源矩形，总计9张源PNG。

客串为轻松虚构演出，黄仁勋使用银发、眼镜和黑皮衣造型，展示买单账单。派对以局部珊瑚/青色灯光、唱片和彩纸体现，未替换用户已选的昼夜底图。金币和连击粒子有数量上限，开启减少动态效果时停用粒子和连续动态。声音由本地WebAudio产生，首次鼠标操作后才解锁，右下角可静音。

event-atlas的实际生成行距不完全等分。构建脚本按透明行间隔读取0–365、365–650、650–940、940–1254四个源区，完整保留鞋底并排除邻行碎片；PNG本身未修改。使用manifest中的cell/rect坐标，不要重新按四等分裁图。
