# 角色表情与四向动作

本轮直接执行用户指定的素材扩充：保留现有角色身份、服装与像素风格，为8位在用角色和5位备用角色补充各20帧透明PNG。既有资产不覆盖。玩家此前授权直接推进，Cortico是否引入由开发判断；无需再确认常规切片与动画选择。

每张图为4列5行。第1行正面站立/两步/眨眼；第2行背面站立/两步/高兴；第3行左侧站立/两步/难过；第4行右侧站立/两步/生气；第5行思考/惊讶/工作/疲倦。每格完整全身、留透明间距，原PNG不裁改。manifest记录读取区域和统一身体基线，左右使用真实绘制帧。

运行时独立表现模块根据实际路径选择四向帧，停车保留朝向，交谈面向玩家；减少动态设置下使用静态帧。近身聊天显示思考、回复表情与错误反馈；工作表现依据实际任务。表情只改变外观，不改变经济或任务调度。模型可返回有限emotion字段；缺省用短句语义规则，避免额外模型请求。素材页提供角色、动作与表情播放预览，备用人物仅作为资产。

当前渲染预加载所有图集，本轮将仅预载现有场景与8张在用动作图；备用图和旧兼容图按需读取，避免无谓增加启动内存。旧图仍能回退。

## Cortico评估

已检查上游README、package.json和docs/personas.md（2026-10-28）：https://github.com/Pal-AI-Lab/Cortico 。其启动要求Node22+，依赖Express/WebSocket，Persona契约包含绝对memoryDir、blobs与部署目录，WebUI是管理客户端，并非可直接放进浏览器的无服务角色SDK。

结论：本轮不安装或拷贝Cortico。按本游戏纯前端、点开即玩约束，直接引入会增加运行服务、配置与适配工作。借鉴Persona/Memory/World分层：现有personas.js定义性格，memory.js管本地记忆，interactions.js合成真实状态，本轮sprite模块仅管表现。不是已集成Cortico，不宣称仅靠框架自动获得人格或表情能力。
