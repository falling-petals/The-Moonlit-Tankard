# 八员工、地窖、Tom、AI记忆与修改器方案

日期：2026-10-27。状态：提案，未实施。代码依据 main / 758595d。

## 当前实现

- 已有六桌坐标，两桌起步，金币扩建至六桌；员工在岗上限三人，仅四名候选。
- 每人十二条字符串记忆，每条最多160字，精确去重、先进先出。保存四十条对话，每次调用传最后六条和记忆。
- 跨日、解雇及重新雇佣保留记忆。同事交流增加双方关系计数，但当前模型上下文未传入关系值。
- 无语义检索、重要性、冲突处理。聊天记下的安排不会自动成为工作规则。
- 地窖在三星解锁：库存入桶、打烊陈酿升级、手动出桶回库存，最高三级，不凭空生产。
- 打开地窖界面目前暂停模拟。没有生产、自动补货、地窖雇员和鼠害。
- 目前只有口碑与二至五星声望，没有经验等级或员工等级。

## 一、人员与桌位

六桌保留两桌起步、金币扩建。设楼上六个岗位、地窖两个岗位，共八位可对话员工；Tom 为单独地窖伙伴，不占八人名额。

- 员工采用稳定ID，增加所属楼层和岗位；调动不可复制人物、工资或记忆。
- 候选至少补足八位，图片与性格由用户后续提供，之前使用明确临时资料。
- 默认建议楼上初始三席，三星、四星、五星各加一席；地窖解锁一席，金币扩至两席。此为提议，非已确认曲线。
- 六桌高峰示例：两厨师、三服务员、一全能。共用队列，不将一人永久绑定一桌。
- 实际雇佣收取费用与日薪，是否雇满取决于客流和供给瓶颈。
- 雇佣菜单分楼上、地窖、伙伴，展示空缺、工资、速度、特长和实际职责。

## 二、生产、搬运和自动补货

新增链条：金币采购原材料 → 地窖批次生产 → 待运库 → 楼上可制作份数 → 厨师制作顾客订单。

- 原 stock 继续表示可制作份数，不把地窖生产视为已经完成顾客订单。
- 两地窖岗位建议一生产员、一搬运员；可换成全能，根据瓶颈调配。
- 每款设置低库存触发线、补货目标、优先级，全店设置自动采购日预算。
- 例：库存低于六份补到十二份，每天最多采购150G。玩家确认预算后自动执行，无需每批批准。
- 首版数值建议每批六份、基础45游戏秒；每份原材料沿用现有成本，人工与效率后续调平衡。
- 无金币、原料、预算或空间时停下并说明原因。手动即时采购保留用于应急。
- 缺口计算扣除在制、已产和在运数量；批次唯一记录，采购、原料消耗、产出与入库分别记账，防止两人重复补货。
- 楼上仓满暂停搬运，不丢货；待运库满再暂停生产。
- 陈酿保持现有规则，从已有库存扣除后入桶，取出搬回同量，可指定最低熟成等级才自动搬回；不与新生产重复计数。
- 两场景共享经营时钟，切换视图不暂停；明确暂停按钮。首版不计算关页离线生产或鼠害。
- 打烊后生产、运输、鼠害暂停，在制批次保留至次日恢复；陈酿依旧打烊结算一次。

## 三、鼠害与 Tom

- 老鼠最多四只，每只降低普通生产产量10%，上限40%；不扣楼上现存库存或封桶陈酿。
- 每批以生产期间的鼠害强度计算损耗；小数余量跨批累计，避免每批六份取整失真或结束前一秒清鼠免除全部损失。
- 解锁地窖后给一晚保护期，此后营业中按模拟时钟和存档RNG出现；界面显示鼠数、损耗与实际产量。
- 鼠标点击老鼠可手动驱赶，没雇Tom也能应急。
- Tom自动巡逻、追踪、扑抓、回位，少量失手和休息动作增加趣味；每日有养护成本，不永久清零鼠害。
- 捕鼠立即降低后续干扰。动作在本地规则运行，不等待大模型；具体形象与性格等用户提供。

## 四、记忆与可执行安排

分开存人物资料、偏好、工作安排、事件经历与关系，禁止将模型随口说的经营成果写成真实事件。

- 固定资料：姓名、性格、口吻、形象引用。
- 长期偏好：对象、内容、来源、时间、重要性、置顶。明确新偏好覆盖同对象旧偏好。
- 工作安排：优先清桌、补货线、预算等结构化白名单规则。模型提出候选，聊天框点“应用安排”，规则校验、执行、返回回执；有记忆不等于已经执行。
- 事件经历：来自游戏真实订单、断货、合作与捕鼠事件，保留参与者和来源ID。
- 关系：传入当前交谈对象的关系值和共同经历。私人对话不全员共享，参与、听到或被转告才形成各自记忆。
- 检索：最近六条对话加当前人物/任务相关的六至十条记忆；明确安排和置顶偏好不被闲聊挤掉，低价值内容可过期。
- 控制：聊天框折叠显示“记住的事”，支持纠正、删除、置顶。
- 本地标签、对象和关键词检索先行，不依赖向量服务。历史扩大后可迁 IndexedDB，并保持完整导入导出与旧档迁移。
- 当前岗位、库存和执行回执优先于旧记忆，避免过期事实误导回应。

八员工不意味着八路持续调用：玩家交谈优先，随后必要服务回应，再是附近闲聊。建议同时最多两请求并给玩家预留容量，环境对话按全店预算限频、同场景择一组，保留流式输出。顾客是规则NPC，模型故障不停止服务、生产与捕鼠。

## 五、开发修改器

本地URL加 ?debug=1 后显示小扳手，全鼠标操作、居中面板。进入时复制正常进度为独立调试档，单独本地存储键，明确标识调试模式，能恢复进入前快照。

- 资源：金币、灵感、九款库存、原材料、待运品、秘方解锁。
- 进度：天数、口碑、声望星级、桌数、人员编制、地窖等级。当前“等级”对应星级，员工等级以后若增加再接入。
- 员工：快速雇满、设置岗位与楼层、测试特长、检查任务和记忆、清除指定测试记忆。
- 环境：老鼠数量、Tom状态、客串、派对、特殊需求、陈酿等级。
- 时间：暂停、1/2/3/10倍、固定步进、下一天。快进走真实模拟与结算，不只改elapsed。
- 预设：六桌高峰、八员工满编、金币不足、满仓、零库存、满鼠害、Tom工作、成熟陈酿。
- 观察器：任务锁、路径、生产运输队列、AI请求与当前注入记忆，不含凭据和请求头。
- 通过专用debug动作修改并校验范围；星级同步里程碑和解锁，打烊与事件沿真实流程，防止重复发奖和坏档。
- 调试加钱不计经营收入，导出只含游戏状态，不含API Key或模型会话配置。
