# 月下酒馆 / The Moonlit Tankard

一个个人本机使用的纯前端像素酒馆 MVP。场景铺满浏览器，白天是暖阳温室，晚上是青蓝雨光；你控制人类店长，与有不同性格和记忆的AI店员一起经营。

## 开始游玩

1. 双击项目目录中的 **start.cmd**，会打开浏览器。
2. **全鼠标操作**：点击地面走动；点击人物、桌子或设施，店长会自动走近。滚轮可稍微拉近镜头。
3. 点击 **开门营业**。员工自动工作，你也可以帮忙：走近待接单餐桌，选择 **我来调这杯**，去吧台制作；做好后点击对应桌子，亲自端送。脏桌可以选择 **亲自收拾桌面**。
4. 点击员工，走近后弹出场景内小对话框；可以点预设话题，也可以输入自己的话。结束交谈后员工继续工作。

底部的菜单、伙伴、原料、布置和手记按钮会带店长走向对应设施。右上角可暂停、调整速度、切换日夜或打开设置。端送途中可以自由改路，订单会继续留在手中；**交还伙伴/放回吧台**会释放订单并返还剩余容量内的原料。

也可以在此目录运行：

```powershell
python tools/launch.py
```

需要本机有 Python 3；游戏本身没有 npm 安装或构建步骤。`npm start` 也可启动。默认地址是 `http://127.0.0.1:4173/`，端口被其他程序占用时会选择后续端口。重复启动会复用已运行的游戏地址，保持浏览器存档连续。启动窗口运行期间保留即可，关闭后可重新启动。

## 大模型连接

启动脚本优先读取 `AI_DASHSCOPE_API_KEY`，也支持 `DASHSCOPE_API_KEY`、`OPENAI_API_KEY`。当前环境已实测百炼：

- 服务地址：`https://dashscope.aliyuncs.com/compatible-mode/v1`
- 默认模型：`qwen-plus`
- 可通过 `AI_BASE_URL`、`AI_MODEL` 覆盖，或在游戏 **设置** 中修改。

环境配置在启动时经一次性浏览器片段交给当前标签页；页面会立即清除该片段。密钥保存在当前标签页会话中，不写入游戏源码、普通本地存档或导出文件。直接点击本地URL时，如果标签页尚未配置密钥，可通过设置填写，或重新双击启动脚本自动读取环境变量。

Python只提供本机静态文件，没有游戏业务后端、API代理或远端存档。模型请求由浏览器直接发给供应商。经营本体不等待模型响应；AI回复失败或超时时仍可继续营业。

## 当前可玩内容

- 4张餐桌、3款可上下架饮品；顾客进店、点单、消费、离店与收桌。
- 4名可雇佣原创AI伙伴：青芽、团团、星禾、弦月，开局青芽在店。
- 岗位：全能服务；调饮专注（制作更快）；接待专注（行走更快并优先收桌）。
- 人类店长四方向行走、亲手调饮、端送和收桌；可接手员工尚在调制的订单，也可交还工作。
- 临时指派：走近餐桌指定伙伴，或交谈时说“优先服务二号桌”，会在当前任务完成后优先处理。
- 真实模型交谈、角色记忆、同事交流与熟悉度、顾客请求回应、活动建议。
- 自动对话按位置、工作事件与冷却触发；同事靠近、空闲时轮流冒出短气泡，接待顾客时在现场回应。每个营业日有限次，可在设置关闭。
- 库存补货、4项设备/布置升级、小小品饮会活动。
- 每日约10分钟，支持暂停与1/2/3倍速；自然昼夜切换及手动日/夜预览。
- 打烊工资与账本、次日经营、本地自动保存、存档导入与导出。

打烊后账本封存，需进入下一天再采购。雇佣和设备属于长期投入，营业净额单列饮品、原料/活动和工资，不是所有资金变动的总和。

## 美术包

访问 **assets/index.html** 或游戏设置中的 **美术资产**：

- 日夜场景原图各1张，1536×1024。
- 店员与顾客透明图集各1张，4人物×4状态。
- 人类店长透明图集1张，正面/背面/左/右×待机/两帧步态/端托盘，共16帧。
- 家具设施、饮品物品透明图集各1张，共32个物件。
- 大厅、吧台、后厨、地窖四区现代场景参考1张。
- `assets/manifest.json`：8张原图尺寸、图集网格与80个透明切片的源坐标。
- `docs/art-guide.md`：配色、渲染层次、像素与图集说明。
- `art-prototype/final/`：完整生成提示词。

当前角色是原创临时形象；待提供各厂商AI形象后替换。MVP可经营范围为地面大厅；厨房和储藏室是场景工作背景，地窖目前是美术参考。配方研究、专属坐姿/工作动画、更深的培养和剧情可继续扩展。

## 验证

```powershell
npm test
python -m unittest discover -s tests -p '*_test.py'
```

浏览器端到端验证需要已安装 Playwright 和 Chrome，并启动本地4173端口：

```powershell
python tools/qa.py
```

该验证会产生少量真实模型请求；可加 `--skip-ai` 跳过真实网络对话。报告位于 `docs/qa-report.json`，截图位于 `screenshots/`。

现已通过46项JavaScript测试、1项启动器回归测试、29项浏览器检查及8项审查补验，包括真实模型互动、鼠标操作、携带读档和完整营业日。详见 `docs/validation.md`。
